−5 m · The Shallows

One URL does the whole job.

A crabcrop URL reads left to right: a signature, then the operations, then the source. Each of your five choices is one part of it, and lights up in the bar above.

Signed URLs, from any stack

Every URL carries an HMAC-SHA256 signature over the operations and the source. Same inputs, same URL, from any of these:

  • TypeScript
  • Python
  • Rust
  • curl
Read the docs on signing

All major formats, in and out

JPEG, PNG, WebP, GIF, AVIF and JPEG XL. Name no format and the browser’s Accept header decides; on a tie, AVIF, then JPEG XL, then WebP.

format(avif) · format(jxl) · format(webp)

Read the docs on formats
Choice 1 of 5Pick a format

No format named: the browser’s Accept header decides.

Sources beyond photos

The source can be one frame of a video, one page of a PDF, an object in S3 or GCS, a local file, or a short root: reference.

frame:50% · page:2 · root:photos/print.jpg

Read the docs on sources

−15 m · The Kelp Forest

51 filters, one chain.

Resize, crop, fit-in and pad are their own path segments. The filters chain inside one filters: segment and run in the order written.

Chained filters

Sharpen, saturate, tone, blur, duotone and more, applied in the order you write them.

filters:sharpen(1.2):saturation(1.1)

Read the docs on filters

Size, crop, fit and pad

Resize to exact pixels, crop to a window that finds the subject, fit inside a box, or pad out to a shape. Each is its own path segment.

crop:1200x630:smart · fit-in · pad

Presets and purge

Server-side preset names keep templates short. Purge one result, or a whole preset group, with signatures from their own subkey.

Smart crop, face safe

Ask for any shape and the crop window moves to the subject. Faces stay whole, never cut at the edge.

Faces, redaction, removal

A YuNet model finds every face: crop to them or blur them. Blur a whole class of thing, like people, before a picture goes out; if detection fails, so does the request. Mark a box, and an inpainting model fills it in.

crop:760x760:face · blurfaces · blurclass(person) · remove_region(40,120,300,200)

−60 m · The Shipwreck

Signed, sealed, provable.

Some links should stay unreadable, some pictures should prove where they came from, and some addresses should never be fetched at all.

Sealed URLs

For links that stay public but unreadable: the whole recipe, operations and source, sealed into one opaque token in the signature’s place. Only the server opens it, and it serves the same render.

s1.<token>/print.jpg

Read the docs on sealed URLs
Choice 5 of 5Seal it, or keep it readable

Readable: the recipe stays in plain sight. It is the right default for most links.

Provenance, checked and signed

Meta reports the Content Credentials a source carries. With your own certificate, outputs are signed as served, the source recorded as an ingredient, so the chain survives the transform.

CRABCROP_C2PA_CERT · CRABCROP_C2PA_KEY

Read the docs on provenance

Private sources blocked by default

The loader refuses sources on loopback, private and other non-public addresses, checked again on every redirect. Allowlisting a host is how you vouch for an internal one.

403 source_forbidden · CRABCROP_ALLOWED_SOURCES

Read the docs on private sources

−500 m · The Twilight Zone

It reads the picture.

Almost no sunlight reaches this far. What a picture holds, a meta answer names: tags with their scores, a line of alt text, the text in it, and a report on the URL itself.

Metadata that describes the picture

JSON meta for every render: size, format, provenance. Richer answers are opt-ins with their own models: CLIP tags and alt text, detections, moderation, embeddings, an aesthetic score, OCR text.

Accept: application/json; detections=1

Read the docs on metadata

Text recognition

Opt a meta request in and the answer reads the picture: the lines of text in reading order, each with its box and a confidence score. The image bytes stay exactly the same.

Accept: application/json; ocr=1

Read the docs on text recognition

URLs that explain themselves

Put explain/ in front of the signature and the server answers with a report on the URL: the signature’s verdict, the source, every operation in plain words, and what will come out.

GET /explain/<signature>/…

Read the docs on explain

−2,500 m · The Vents

The engine at the bottom.

Everything above runs on what is down here: one Rust binary, the libraries that build its URLs, and a server that agents can talk to.

One binary, built in Rust

Install it, give it a secret, and request images with the operations written into the URL. No pre-generated thumbnails, no build step: the URL is the API.

CRABCROP_SECRET=… crabcrop

Read the docs on getting started

SDKs and loaders

Build and sign the same URL from TypeScript, Python, or the Rust crate the server verifies with. Loaders drop it into your framework’s image component:

  • Next.js
  • Nuxt
  • Hydrogen
  • Astro
  • SvelteKit

npm install @crabcrop/url

Read the docs on SDKs and loaders
