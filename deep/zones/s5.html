−500 m · The Twilight Zone

It reads the picture.

Almost no sunlight reaches this far. What a picture holds, a meta answer names: tags with their scores, a line of alt text, the text in it, and a report on the URL itself.

Metadata that describes the picture

JSON meta for every render: size, format, provenance. Richer answers are opt-ins with their own models: CLIP tags and alt text, detections, moderation, embeddings, an aesthetic score, OCR text.

Accept: application/json; detections=1

Read the docs on metadata

Text recognition

Opt a meta request in and the answer reads the picture: the lines of text in reading order, each with its box and a confidence score. The image bytes stay exactly the same.

Accept: application/json; ocr=1

Read the docs on text recognition

URLs that explain themselves

Put explain/ in front of the signature and the server answers with a report on the URL: the signature’s verdict, the source, every operation in plain words, and what will come out.
