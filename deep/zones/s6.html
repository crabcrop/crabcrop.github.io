The engine at the bottom.

Everything above runs on what is down here: one Rust binary, the libraries that build its URLs, and a server that agents can talk to.

One binary, built in Rust

Install it, give it a secret, and request images with the operations written into the URL. No pre-generated thumbnails, no build step: the URL is the API.

CRABCROP_SECRET=… crabcrop

SDKs and loaders

Build and sign the same URL from TypeScript, Python, or the Rust crate the server verifies with. Loaders drop it into your framework’s image component:

  • Next.js
  • Nuxt
  • Hydrogen
  • Astro
  • SvelteKit
