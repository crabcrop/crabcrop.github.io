Blazing fast,
on-demand images.

Crabcrop is a Rust-built, lightning-fast on-demand image API supporting all major formats in and out, with over 50 filters and AI features like background removal. It resizes, crops, converts, and filters your images straight from a signed URL.

curl --proto '=https' --tlsv1.2 -LsSf https://github.com/dayvson/crabcrop/releases/latest/download/crabcrop-installer.sh | sh

One URL does the whole job.

A crabcrop URL is a chain: a signature, then operations, then the source. Every link Snap passes is one part of it, and you pick some of them on the way down.

Signed URLs, from any stack

Every URL carries an HMAC-SHA256 signature over the operations and the source. Sign it from TypeScript, Python, Rust or plain curl: same inputs, same URL.

All major formats, in and out

JPEG, PNG, WebP, GIF, AVIF and JPEG XL, in and out. Name no format and the Accept header decides: AVIF first, then JPEG XL, then WebP.

format(avif) · format(jxl) · format(webp) Read the docs
Choice 1 of 5 Pick a format

Each school of fish is one format. Pick one and it goes on your chain.

With no format named, the schools race: AVIF wins, then JPEG XL, then WebP. That's the order of your browser's Accept header.

More than photos

The source can be one frame of a video, one page of a PDF, an object in S3 or GCS, a local file, or a short root: reference.

  • s3:// · gs:// Objects in S3 and GCS
  • file A local file
