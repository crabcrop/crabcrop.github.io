0 m · The Marina

Blazing fast,
on-demand images.

Crabcrop is a Rust-built, lightning-fast on-demand image API supporting all major formats in and out, with over 50 filters and AI features like background removal. It resizes, crops, converts, and filters your images straight from a signed URL. One binary, no pre-generated thumbnails, no build step.

curl --proto '=https' --tlsv1.2 -LsSf https://github.com/dayvson/crabcrop/releases/latest/download/crabcrop-installer.sh | sh

    Provenance, checked and signed

    Meta reports the Content Credentials a source carries. With your own certificate, outputs are signed as served, the source recorded as an ingredient, so the chain survives the transform.

    CRABCROP_C2PA_CERT · CRABCROP_C2PA_KEY Read the docs

    Private sources blocked by default

    The loader refuses sources on loopback, private, and other non-public addresses, checked again on every redirect. Allowlisting a host is how you vouch for an internal one.

    Metadata that describes the picture

    JSON meta for every render: size, format, provenance. Richer answers are opt-ins with their own models: CLIP tags and alt text, detections, moderation, embeddings, an aesthetic score, OCR text.
