# Fonts

Latin subsets of three SIL Open Font License 1.1 families, taken from the
Fontsource packages (`@fontsource-variable/*`, version 5.3):

| File | Family | Axes |
| --- | --- | --- |
| `fraunces-latin-soft-normal.woff2` | Fraunces | weight, SOFT |
| `figtree-latin-wght-normal.woff2` | Figtree | weight |
| `jetbrains-mono-latin-wght-normal.woff2` | JetBrains Mono | weight |

The Fraunces license is in `OFL-Fraunces.txt`; Figtree and JetBrains Mono
ship under the same license (https://openfontlicense.org).
