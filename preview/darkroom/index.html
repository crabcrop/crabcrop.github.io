Every picture,
developed on demand.

crabcrop is an on-demand image service written in Rust and released as open source. It resizes, crops, converts, and finishes photographs straight from a signed URL, on a server you run yourself. One binary. No pre-generated thumbnails, no build step.

The process / Four baths

From negative to print, in one URL.

A darkroom print passes through its baths in a fixed order. A crabcrop URL works the same way: the source goes in, the recipe is applied in the order written, and what comes out is finished, checked, and signed.

Stage 01 / Expose

Every format walks in, every format walks out

JPEG, PNG, WebP, GIF, AVIF, and JPEG XL, in and out. HEIC and HEIF decode only; SVG decodes, sanitized and rasterized. Name no format and the visitor's Accept header decides: AVIF first, then JPEG XL, then WebP. An explicit format(...) always wins.

The negative can be more than a still: one frame of a video, one page of a PDF, an object in S3 or GCS, a local file, or a short root: reference the server expands against its own origins. Originals can also arrive through the signed upload endpoint, off by default.

format(avif) · format(jxl) · frame:50% · page:2 · root:photos/cat.jpg
Stage 02 / Develop

The recipe is written in the URL itself

Resize, crop, fit-in, and pad are their own path segments. The 45 filters chain inside one filters: segment, everything running in the order written, the way a darkroom notebook records a print: this bath, then that one, for this long.

Server-side preset names keep templates short, and each format takes its own encoder settings, so the same negative can be developed a dozen ways without a single file stored in advance.

filters:sharpen(1.2):saturation(1.1) · preset:og-card
Stage 03 / Fix

AI finishes the print, in process

Your ONNX models, inference in process. Background removal keeps the subject and makes the background real alpha. Studio mode cuts the subject out and composites it onto a clean backdrop over a soft contact shadow, or reframes a scene on its subject and corrects the light.

Smart crop finds the subject and keeps detected faces whole; objects crop works by class. Upscale rebuilds detail instead of stretching pixels, and redaction never guesses: a detection failure fails the request. No model configured means a clean 501, never a silent fallback.

filters:removebg · filters:studio(product) · crop:760x760:smart · filters:upscale(2)
Stage 04 / Inspect

Checked, described, and sealed before it dries

Ask for JSON and get dimensions, format, byte size, and provenance for every render. The richer answers are opt-ins, each with its own model set: CLIP tags and alt text, detections, moderation verdicts, embeddings, an aesthetic score, and OCR that reads the text in the picture, line by line, with boxes and confidence scores.

Provenance is checked and signed: meta reports the Content Credentials a source carries, and outputs can be C2PA signed with your own certificate, the source recorded as an ingredient, so the chain survives the transform. A source policy decides which origins the server will fetch from at all, and explain/ reports on any signed URL instead of serving it.

Accept: application/json; ocr=1 · GET /explain/<signature>/...

The signature / Fixed in advance

Sign a URL, from any stack.

Every URL carries an HMAC-SHA256 signature over the operations and the source, lowercase hex. Sign with the TypeScript or Python SDK, the crabcrop-url Rust crate, or plain curl: same inputs, same URL.

printf '%s' 'crop:1200x630:smart/filters:format(webp):quality(80)/https://example.com/photo.jpg' \
  | openssl dgst -sha256 -hmac 'demo-secret'
# SHA2-256(stdin)= ca3d1f22f4cc3860926608df02383f46dcf74af9a4e1bc26b1a00c644f55f300
import { buildURL } from "@crabcrop/url";

const url = buildURL({
  base: "https://img.example.com",
  secret: "demo-secret",
  operations: "crop:1200x630:smart/filters:format(webp):quality(80)",
  source: "https://example.com/photo.jpg",
});
from crabcrop_url import build_url

url = build_url(
    base="https://img.example.com",
    secret="demo-secret",
    operations="crop:1200x630:smart/filters:format(webp):quality(80)",
    source="https://example.com/photo.jpg",
)
use crabcrop_url::{build_url, sign};

let signature = sign(secret, "crop:1200x630:smart/filters:format(webp):quality(80)/https://example.com/photo.jpg");
let url = build_url(base, secret,
    "crop:1200x630:smart/filters:format(webp):quality(80)",
    "https://example.com/photo.jpg")?;

Note / Each snippet signs the same example with the sample secret demo-secret. Swap in your base, your secret, and your operations.

Note / The source can be a short root reference instead of a full URL, like root:photos/cat.jpg: the server expands it against an origin configured on the server, so the origin itself never appears in the URL.

Note / A URL can also be sealed: the whole recipe, operations and source, encrypted into one opaque token in the signature slot, for links that have to stay public but unreadable. The readable form stays the default. See sealed URLs in the docs.
