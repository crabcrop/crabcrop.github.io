Blazing fast,
on-demand images.

Crabcrop is a Rust-built, lightning-fast on-demand image API supporting all major formats in and out, with over 50 filters and AI features like background removal. It resizes, crops, converts, and filters your images straight from a signed URL.

The ship's log of your picture

    Provenance, checked and signed

    Meta reports the Content Credentials a source carries. With your own certificate, outputs are signed as served, the source recorded as an ingredient, so the chain survives the transform.

    CRABCROP_C2PA_CERT · CRABCROP_C2PA_KEY Read the docs
    1. photos.example.com/print.jpgfetched
    2. 10.0.0.7/admin.png403
    3. 169.254.169.254/latest/meta-data403
    4. localhost:9000/backup.jpg403

    Private sources blocked by default

    The loader refuses sources on loopback, private and other non-public addresses, checked again on every redirect. Allowlisting a host is how you vouch for an internal one.

    403 source_forbidden · CRABCROP_ALLOWED_SOURCES Read the docs
